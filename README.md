# Purchase Order Management

Java console application to manage purchase orders with a MySQL database.

## Technologies
- Java 14
- MySQL 8
- JDBC
- Maven
- DAO Pattern

## Structure
- MODEL: PedidoCompra, DetallePedido
- DAO: PedidoCompraDAO, DetallePedidoDAO
- CONEXION: ConexionBD
- App: Main menu

## Database
Run the `BASE_DE_DATOS.sql` script in MySQL before starting the application.
